# 02 — Evidence Register

**What this is.** Every factual claim the plan relies on, in one table per topic. Each entry says where it came from, what it **does** support, and what it **does not** support. Other documents cite entries by ID, for example [E-REG-02].

**How to challenge it.** Pick any ID, open the source, and check the "supports" column. If the source does not say that, the claim is wrong and every place that cites it should change. The review log ([03](03-review-log.md)) records each correction made so far.

**Source types.** *Primary* means the original document: a statute, a paper, a vendor's own pricing or terms page. *Secondary* means a summary by someone else. *Own test* means a test in this repository that you can rerun. *Vendor claim* means a company describing its own product.

**Confidence.** *High*: primary source read directly, claim matches its wording. *Medium*: secondary source, or primary source with interpretation. *Low*: unverified, conflicting, or inferred.

All sources were read on **31 October 2026** unless noted. Entries were corrected the same day after an adversarial review ([03](03-review-log.md) Part E); each correction is noted in its row.
